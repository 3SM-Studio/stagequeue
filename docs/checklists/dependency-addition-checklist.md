# Dependency Addition Checklist

- [ ] Problem is worth a dependency.
- [ ] Existing platform/framework/project code cannot solve it cleanly.
- [ ] Package is maintained.
- [ ] License is acceptable.
- [ ] Transitive dependency count is acceptable.
- [ ] Bundle/runtime impact is acceptable.
- [ ] Security posture is acceptable.
- [ ] Removal/replacement path is known.
- [ ] Dependency is isolated behind adapter when high-risk.
- [ ] PR explains why this dependency is needed.
