# Frontend Feature Checklist

- [ ] Server state vs client state is clear.
- [ ] `use client` is used only where needed.
- [ ] Loading, empty, error and success states exist.
- [ ] Form fields have labels and accessible error messages.
- [ ] Keyboard navigation and focus behavior work.
- [ ] Backend remains source of truth for validation/security.
- [ ] API errors are mapped to user-friendly messages.
- [ ] No secrets or server-only data are exposed to browser.
- [ ] Bundle/hydration impact is considered.
- [ ] Critical user flow has test coverage or manual QA notes.
