# Incident Response Checklist

- [ ] Severity assigned.
- [ ] Incident owner assigned.
- [ ] User impact stated.
- [ ] Current mitigation chosen.
- [ ] Rollback/feature flag considered.
- [ ] Timeline started.
- [ ] Logs/metrics/traces gathered.
- [ ] Communication channel established.
- [ ] Postmortem owner assigned.
- [ ] Action items created after resolution.
