# Release Checklist

- [ ] Version/release scope is clear.
- [ ] Migrations identified and ordered.
- [ ] Env var changes documented.
- [ ] Feature flags documented.
- [ ] Rollback or roll-forward plan exists.
- [ ] Smoke tests defined.
- [ ] Monitoring checks defined.
- [ ] Owner/on-call person identified.
- [ ] User/operator communication needed? yes/no.
- [ ] Post-release verification completed.
