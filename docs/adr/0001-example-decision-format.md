# ADR-0001 — Example decision format

## Status

Example

## Context

A decision is needed when a choice affects architecture, security, operations, API contracts, data model, deployment or long-term cost.

## Decision

Record the choice clearly.

## Consequences

State what becomes easier and harder.

## Rejected alternatives

List serious alternatives and why they lost.

## Revisit trigger

Define the signal that would make this decision stale.
