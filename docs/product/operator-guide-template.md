# Operator Guide Template

## Purpose

Explain how a non-developer operator uses the product safely.

## Common workflows

- Create event
- Activate event
- Open public queue
- Approve/reject requests
- Pause queue
- Close/archive event

## Common problems

| Problem | What it means | What to do |
|---|---|---|
| Public user cannot join | Event inactive or queue disabled | Check event status and public settings |
| Queue not updating | Network/realtime issue | Refresh, check status, escalate if persistent |
